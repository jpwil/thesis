This thesis is designed as a digitally navigable document. Hyperlinks are provided to facilitate movement between chapters, figures, tables, appendices, and references. The complete and most recent \LaTeX\ source, with compiled PDF, is available as a git repository: \url{https://github.com/jpwil/thesis}.

Supplementary materials, including R code, are published in a separate git repository: \url{https://github.com/jpwil/dphil}. The accompanying \href{https://github.com/jpwil/dphil}{README.md} file provides further details to facilitate navigation of the repository contents.

Please note that the curated source datasets and R code used for dataset cleaning are not included in the supplementary materials repository. These materials contain direct references to the curated datasets and are not available in the public domain. Further details on data access requests can be found on the IDDO website: \url{https://www.iddo.org/vl/data-reuse/accessing-data}.
